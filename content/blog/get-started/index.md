# Markdown Language

Markdown is a lightweight markup language used to format text.

It is widely used for:
- Documentation
- README files
- Blogs and static websites

## Advantages
- Easy to learn and use
- Readable in plain text format
- Fast writing without complex syntax

## Example 

You can create:
- **Bold text**
-*Italic text*
- Lists
- Links

Markdown is very popular among developers because it simplifies writing structured documents.
